UltraServers cheat sheet

Prints cleanly. Facts as of Aug 2026 — pricing moves fast, re-check before quoting.

What it is

An EC2 instance that is an entire rack: multiple physical servers fused into one virtual machine full of Trainium chips, so 64–144 chips act as one accelerator. Announced Dec 3, 2024 (Trn2). The product you rent with one API call and one bill.

Two interconnects

  • NeuronLink — scale-up, inside the box: Trn2 does 1,024 GB/s per chip intra-server, 256 GB/s inter-server; Trn3 uses the NeuronSwitch-v1 fabric. Veins inside the body.
  • EFA (Elastic Fabric Adapter) — scale-out, box to box across the cluster. Highways between cities.
  • UltraClusters wire tens of thousands of UltraServers into a petabit-scale nonblocking network; 3rd-gen clusters reportedly scale to ~1M chips.

Software: no CUDA

  • The Neuron SDK replaces NVIDIA's stack: a compiler mapping PyTorch/JAX graphs to Trainium's instruction set, NeuronX Distributed (tensor/pipeline/data/sequence/context parallelism), NKI (Python DSL for custom kernels).
  • vLLM, Hugging Face TGI, DeepSpeed, and JAX run on top.
  • Flag example: NEURON_CC_FLAGS="--target=trn2 --lnc=2" — compile for this silicon generation, use 2 link cores for chip-to-chip traffic.

Who rents it

  • Anthropic — Project Rainier: ~500K Trainium2 chips online Oct 29, 2025, scaling past 1M. Mostly serves inference; training runs in the evenings when inference load drops.
  • OpenAI — 7-year $38B AWS deal (Nov 2025) including Trn2 UltraServers.
  • Apple (reported multi-year Trainium2 commitment), Databricks, Hugging Face.
  • Claude on Bedrock runs on Trainium — you may already be using one.

The pricing anomaly

Third-party trackers: trn2.48xlarge ~$4.80/hr on-demand but spot ~$8.60–8.72/hr — spot ABOVE on-demand. Trainium is scarce: capacity is allocation-controlled via Capacity Blocks (1–64 instances, up to 6 months) and multi-year private agreements, so the leftover spot market inverts. tracker · Capacity Blocks

Fault tolerance (nodes die, a lot)

  • At 100K-chip scale, node failures are daily. Meta: a GPU failure roughly every 3 hours during LLaMA training.
  • NDTL (Neuron Distributed Training Library) checkpointing raised measured cluster uptime 77.8% → 98.8%.
  • Tiered checkpoints: fast local NVMe ~every 5 min, durable S3 every hour.
  • Checkpointless training replicates state peer-to-peer: recovery in minutes instead of up to an hour.

What UltraServer SDEs fight daily

  • Node failures and fast resume (checkpoint tiers, peer-to-peer state).
  • Collectives: all-reduce over the chip mesh — hierarchical, reduce within the 64-chip node first, then across nodes over EFA (~1–2 µs per-hop latency on NeuronLink).
  • Compiler engineering: operator fusion, memory planning (HBM vs on-chip scratchpad), quantization, compile caches so customers don't recompile per boot.
  • Power and cooling: ~35–40 kW per box; a planned Indiana campus is >2.2 GW. The metric of record shifted from FLOPs to tokens-per-megawatt.
  • Model bring-up: every new architecture (GPT-OSS, DeepSeek-R1 distills, Qwen3) needs optimization passes; GPT-OSS-120B hits 3x throughput per chip on Trn3 (AWS claim).
