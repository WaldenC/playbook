What it is

Managed model access: ~200 models behind one API, pay per token, no machines to run. Scale claims: 125K+ customers, ~80% of the Fortune 100, multibillion-dollar run rate, more tokens in Q1 2026 than all prior years combined. source

Pricing & privacy

  • Per input/output token; output typically 4–10x the input price.
  • Batch inference: ~50% off, for deferrable work.
  • Claude and OpenAI prices match first-party prices — no markup.
  • Privacy: prompts never used for training, not shared with model providers, no retention by default.

Serving mechanics

MechanismNumbers that matter
Prefill vs decodePrefill = read whole prompt, produce first token. Decode = one token at a time, memory-bandwidth-bound.
TTFT vs tokens/secThe two metrics SDEs guard: time-to-first-token, then output speed.
Prompt caching (cachePoint)Cache read up to 90% cheaper than write; AWS claims up to 90% cost / 85% TTFT reduction. Community benchmark on Llama 3.3 70B: ~80 ms hit vs ~800 ms miss — a 10x gap.
Cross-region inference profilesSpread load across regions; us-east-1 ↔ us-west-2 ~65 ms RTT, to ap-southeast-1 ~220 ms.
Quota accountingTokens-per-minute; output tokens weighted 5:1.
Latency-optimized inferencePer-request flag; up to 51.65% lower TTFT P50 and 97.1% lower P90 for Llama 3.1 70B (AWS claim, Trainium 2).

Customer features beyond the raw API

  • Guardrails: content/topic/PII filters in the request path; multimodal image filters (up to 88% of harmful content blocked, AWS claim); standalone ApplyGuardrail API.
  • Knowledge Bases: managed RAG — chunking, embeddings, vector store, hybrid search, GraphRAG (GA Mar 2025), natural-language-to-SQL.
  • Agents: Bedrock Agents (action groups + KBs) and AgentCore (GA Oct 2025) — Runtime, Memory, Gateway, Identity, Observability, Code Interpreter, Managed Browser, Evaluations; A2A protocol; policy gates with automated reasoning.
  • Rufus (Amazon's shopping assistant, 250M customers in 2025) dogfoods intelligent prompt routing: complex queries → Claude Sonnet, simple ones → small fast models.

When it breaks

Oct 20, 2025: a DynamoDB DNS failure cascaded and the Converse API failed for ~2.5 h with ConflictException: Lock already in use. This is why cross-region profiles exist. outage report

What Bedrock SDEs fight daily

  • Model onboarding without breaking customers pinned to old versions (model-version IDs keep old callers stable).
  • Latency SLOs: TTFT percentiles and cache-hit ratios.
  • Multi-tenant packing: continuous batching and KV-cache memory management across many customers per accelerator.
  • Capacity spikes: absorbed via cross-region profiles and quota controls.
