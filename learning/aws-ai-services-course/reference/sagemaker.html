What it is

The ML platform: train, deploy, and operate your own models on your own containers and hardware. Renamed SageMaker AI Dec 2024/Feb 2025. Unified Studio (GA Mar 2025) is the IDE bundling data, analytics, and AI (Athena, Glue, Redshift, Bedrock, Airflow). Spot training: the discount aisle

  • Up to 90% off list price (real-world 60–70%); AWS can reclaim with ~2 minutes' notice.
  • You set MaxWaitTimeInSeconds (total budget, retries across reclaims) and CheckpointConfig (S3 location). Recommended cadence: checkpoint every 15–30 min.
  • Cinnamon AI: 70% cost savings + 40% more daily jobs.

Packing: one GPU, many tenants

  • Inference components slice one instance across models (e.g., Stable Diffusion 1 GPU + Llama 2 2 GPUs on one g5.12xlarge), each with per-model autoscaling.
  • Model pinning keeps N warm copies; least-connections routing spreads load.
  • Tiered KV cache + intelligent routing (Nov 2025, HyperPod): up to 40% latency reduction, 25% throughput gain; Llama-3.1-70B P50 TTFT −72% at 8k context, −94% at 64k.
  • Deployment safety: rolling updates — all-at-once / canary / linear / blue-green, per-component capacity percentages.

Fault tolerance

  • Meta reported a GPU failure roughly every 3 hours during LLaMA training — long runs must assume death.
  • HyperPod self-healing detects and replaces failed nodes.
  • Dec 2025 checkpointless training: model state replicated peer-to-peer; recovery in minutes; >80% downtime reduction. Amazon Nova trained on "tens of thousands of accelerators" with it.
  • Elastic training (2025): jobs grow mid-run opportunistically, preserving global batch size, with anti-thrashing backoff.

Capacity procurement

HyperPod Flexible Training Plans: reserve 1–256 instances, up to 8 weeks ahead, for up to 6 months; instant start within 30 min; if no continuous block exists the system auto-splits into two segments and returns up to 3 options.

The engine story

SageMaker doesn't build its own LLM serving engine as the primary path — it hosts open engines. First SGLang DLC Nov 2025 (sglang:0.5.5); first-party vLLM DLC Dec 2025; BYOC with vLLM/SGLang/TensorRT-LLM. AWS differentiates with the infrastructure around the engines: Fast Model Loader, tiered KV cache, inference components.

Rest of the catalog (one-liners)
