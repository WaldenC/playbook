Lesson 0011 · The capstone

The five ghosts

Ten lessons, three doors, five ghosts. Every mechanism you met pins to one of five recurring problems — and the tool differs while the ghost never dies.

The same pager, three teams

Give an SDE from each team the same Tuesday: time-to-first-token (TTFT) percentiles and cache-hit rates in the morning standup, cluster-utilization graphs at noon, an autoscaling design review mid-afternoon, a capacity-planning meeting at four, and a pager that fires at night when a node dies. The dashboards look alike because the underlying problems are the same five. Call them the five ghosts: cold start, scale, packing, crash, scarcity.

The names hide the mechanics, so pin them down now. Cold start is the delay before a warm copy of the model exists. Scale is growing the fleet with demand — autoscaling. Packing is utilization: squeezing more tenants onto the same silicon. Crash is hardware and software failure, and fault tolerance. Scarcity is capacity and cost — getting the chips at all.

The matrix

Every mechanism from lessons 0002 to 0010 lands in exactly one cell. Read a row and you see the same ghost in three costumes.

The contrast is the lesson. Bedrock fights a ghost by routing and caching, SageMaker by scheduling, UltraServers by fusing — 64 to 144 chips made to act as one.

Same ghost, different floor

Take cold start. Bedrock's weapon is a cache: a cachePoint in the request turns an ~800 ms miss into an ~80 ms hit, a 10x TTFT gap. SageMaker's weapons are faster boots: container image caching, and Fast Model Loader streaming 8 MB weight shards straight to GPU memory via DMA, up to 15x faster. On UltraServers the rack is long-lived, so the ghost mutates into recompilation — and the fix is a persistent compile cache instead.

Scarcity inverts the pricing tell. Spot GPU capacity on SageMaker costs up to 90% less; Trainium spot costs more than on-demand, about $8.7 versus $4.8 per hour. One market sells idle capacity at a discount; the other rations every chip through allocations, multi-year deals, and Capacity Blocks.

The decision rules, once more

The three doors still close in one breath, from lesson 0001: model already exists → Bedrock; build or own the model → SageMaker AI; build the machine models run on → UltraServers. And the doors still nest — Bedrock's models run on Trainium UltraServers, and SageMaker rents the same racks.

The ghosts don't care which door you stand at. Pick the door by what you want to own; the pager finds you either way.

The ghosts never die

No team defeats a ghost; teams move them around. Checkpointless training trades checkpoint cost for memory — peer-to-peer state replication recovers a run in minutes instead of an hour. Managed Spot trades cost for reclamation risk: up to 90% off, provided AWS can take the machine back with a two-minute warning. Prompt caching trades memory for TTFT. Every fix is a trade, which is why the same five ghosts keep coming back — next quarter, in new costumes.

Taxi, garage, factory floor — and the five ghosts haunting all three. That's the whole map.

Try it

Name the ghost

Bedrock TTFT jumps from ~80 ms to ~800 ms after a customer stops reusing its system prompt. Which ghost is this?

The prompt stopped matching the cached prefix, so the whole prompt re-runs prefill — the 80 vs 800 ms gap in one sentence. Routing to another region is the scale ghost's weapon, and tenant count is packing's.

Traffic doubles at noon. A SageMaker autoscaler must grow the fleet without killing in-flight requests. Which ghost is this?

Scale is the ghost that grows the fleet with demand. SageMaker fights it with target-tracking autoscaling on inference components, cooldowns, and scale-in logic that never kills in-flight requests. Packing is about fitting models onto instances, not growing the fleet.

A 100K-chip training run loses a node every few hours. Which ghost does the UltraServers team fight, and with what weapon?

Node failures are routine at 100K-chip scale — Meta logged a GPU failure roughly every 3 hours during LLaMA training. NDTL checkpointing lifted measured cluster uptime from 77.8% to 98.8%. Elastic training is the scale ghost's weapon on UltraServers.

On Trainium, the spot price sits ABOVE the on-demand price. Which ghost, and which mechanism explains it?

Spot usually sells idle capacity cheaply; when demand exceeds supply the market inverts. Trainium capacity is allocation-controlled — multi-year deals and Capacity Blocks — so leftover spot prices ABOVE on-demand, about $8.7 vs $4.8 per hour.
